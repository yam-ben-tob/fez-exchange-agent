🏗️ System Architecture & Logic

System Purpose

Filters universities by academic/language/availability criteria, ranks by preferences, and analyzes top matches for logistics and fit using a multi-agent approach.

Agentic Workflow

  • Filter Agent (SQL): Deterministic filtering via Supabase to ensure hard requirements are met.
  • Ranker Agent (LLM): Heuristic scoring based on free-text user "vibes" and preferences.
  • Analyzer Agent (RAG): Retrieval-Augmented Generation using Pinecone to extract logistical facts from PDF factsheets.
